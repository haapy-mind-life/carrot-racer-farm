# 박현준 월드 확장

목표: 넓은 월드에서 걸어가서 놀고, 놀이를 마치면 같은 위치로 돌아온다.

확인된 문제: 기존 월드는 화면 비율 좌표와 keydown 단위 이동을 사용한다. 친구의 보물찾기/산책 라벨은 실제 게임으로 연결되지 않는다. 러너는 별도 엔진이 이미 이식되어 있다.

구현 순서:
1. 2800×1800 월드, 시간 기반 이동, 충돌, 카메라, 6개 입구. 기존 world-exploration 모듈은 기존 테스트와의 호환을 위해 유지한다.
2. 동일한 SVG 캐릭터를 월드·미니게임·러너에서 사용한다. 민트/복숭아/라벤더 의상을 보존한다.
3. 보물찾기(6개/75초), 별 줍기(18개/45초), 낚시(5회/45초). 설명·시작·일시정지·결과·재시작·나가기 제공.
4. 기존 저장을 이관하며 별도 미니게임 기록과 중복 정산 방지 추가. 러너 기록과 분리.
5. 방향키/WASD 연속 이동, E 상호작용, 모바일 누르고 이동. 포커스 이탈 시 입력 초기화.
6. 엔진 테스트, 타입 검사, 브라우저에서 이동/진입/귀환/보상 확인. GitHub PR로 전달하고 배포와 구분한다.

검증 기준: 모든 입구가 걸어서 도달 가능하고, 장애물을 통과하지 않으며, 카메라가 맵 밖을 보여주지 않는다. 모든 새 미니게임은 시간 종료/성공/재시작이 가능하다. 재렌더링과 중복 이벤트로 보상이 두 번 지급되지 않는다.
