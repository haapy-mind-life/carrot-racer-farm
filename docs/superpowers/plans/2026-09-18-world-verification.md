# 월드 확장 검증 기록

기준 커밋: 060e47e31593e4af42874b1a4790f82a465abeb1

## 제공 기능
- 2800×1800 월드, 플레이어 추적 카메라, 지도, WASD/방향키 연속 이동, 모바일 누르고 이동.
- 집/농장/러너 입구 및 토토 보물 숲/루루 별빛 공원/낚시 호수. 건물·호수 충돌과 도달 가능 경로.
- 토끼 후드 캐릭터를 월드, 의상, 미니게임, 러너에 공통 사용.
- 보물찾기: 75초, 보물 6개. 별 줍기: 45초, 세 차례 합계 18개. 낚시: 45초, 초록 구간에서 5회.
- 각 미니게임 설명/시작/일시정지/성공/시간종료/재시작/복귀. 중도 나가기는 보상 없이 종료, 완료한 판은 결과에 따라 보상.
- 미니게임 최고 기록과 중복 정산 방지 ID를 기존 저장 형식에 추가. 기존 러너/돈/가구/농장 기록 보존.
- 러너는 기존 5단계 엔진을 유지하고 키보드 조작 보강. 같은 SPA 세션에서 월드 출입 위치 유지(새로고침 시 광장).

## 로컬 확인
- `node --test src/lib/*.test.ts src/game/*.test.ts`: 27개 통과.
- 변경 컴포넌트 및 의존 모듈: 원래 tsconfig 엄격 옵션으로 타입 검사 통과.
- 변경 TS/TSX 파일 ESLint 통과.
- 원래 React 컴포넌트와 실제 TanStack Router를 연결한 Vite 검증용 클라이언트 빌드 통과.
- jsdom 기반 컴포넌트 통합 검증: 키 유지 이동, blur 정지, 공원 입구, 미니게임 이동, 일시정지, 타임아웃, 중복 보상 방지, 재시작, 복귀, 러너 라우트 진입/복귀 통과. Canvas 시각 렌더링은 이 테스트 대상이 아님.

## 한계와 출시 전 확인
브라우저 도구에서 로컬 주소가 ERR_BLOCKED_BY_CLIENT로 차단됨. 따라서 실제 브라우저 화면 품질, 터치 기기의 손맛, 러너 Canvas 이미지 렌더링은 아직 직접 눈으로 확인하지 못했다. 원본 전체 앱의 빌드는 GitHub CI 결과로 별도 확인한다. PR 생성은 서비스 배포와 다르다.

수동 확인: 데스크톱/휴대폰에서 각 입구로 이동 → 각 놀이 완료/나가기 → 지갑·최고기록 확인 → 러너·농장·집 왕복 → 새로고침 후 저장 확인.
