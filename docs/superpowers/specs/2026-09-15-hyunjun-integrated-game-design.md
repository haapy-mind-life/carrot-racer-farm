# 박현준 게임 통합 디자인

## 목표
`carrot-racer-farm`을 단일 박현준 게임 저장소로 사용하고, `park-runner-game`의 핵심 러너 경험을 이식해 `우리 마을 → 달리기 / 반짝 농장 / 우리 집` 세 미니게임이 하나의 저장 데이터와 캐릭터 테마를 공유하도록 한다.

## 사용자 경험
- 시작 화면은 카드 메뉴가 아니라 현준이가 움직이는 작은 마을이다.
- 마을에서 달리기, 농장, 우리 집을 선택한다.
- 모바일 터치가 기본이며 텍스트 입력/키보드 UI를 사용하지 않는다.
- 공통 캐릭터는 귀여운 곰돌이 후드 스타일이며 옷 색을 바꾸면 러너에도 동일하게 적용된다.

## 달리기
- 기존 러너의 5단계(달리기, 몬스터, 비밀 사다리, 하늘 모험, 챔피언/크레인)와 한 손가락 조작을 유지한다.
- 기본은 `산책 모드`: 느린 속도, 넉넉한 보호막, 자동 점프/비행 보조, 크레인 재시도 허용.
- `도전 모드`: 더 빠른 속도, 하트 3개, 수동 조작 비중 증가.
- 공격 표현은 어린이 친화적인 방울/별/바나나 효과로 렌더링한다.
- 완주 기준은 1000점이며 달리기에서 얻은 별코인은 공통 지갑에 저장한다.

## 반짝 농장
- 6개 밭, 5개 작물(무, 사탕무, 양상추, 당근, 해바라기)을 유지한다.
- 동글 무 씨앗은 무료로 시작할 수 있다.
- 심기 → 물 주기 → 수확 흐름은 큰 터치 버튼/밭 직접 터치로 수행한다.
- 다섯 번째 수확마다 확정 반짝 보너스를 제공해 랜덤 좌절을 줄인다.

## 우리 집
- 신규 집 꾸미기 화면을 추가한다.
- 기본 무료 가구: 구름 침대, 꽃잎 러그, 새싹 화분.
- 추가 가구는 별코인으로 한 번 구매하면 계속 소유한다.
- 6개 배치 슬롯, 3개 벽지, 3개 무료 의상 프리셋을 제공한다.

## 데이터/호환성
- 새 저장 키 `hyunjun-game-v2`를 사용한다.
- 기존 `hyunjun-game-v1` 및 `runner-best` 값을 읽어 v2 상태로 마이그레이션한다.
- 저장 데이터는 경계 검사, 숫자 상한, 알려진 enum 필터링으로 방어한다.
- localStorage 실패 시 현재 세션 플레이는 유지하고 사용자에게 저장 경고를 표시한다.

## 기술 구조
- `src/game/`: 순수 러너 엔진, 진행/충돌 규칙, Canvas 렌더러.
- `src/lib/world-model.ts`: 공통 게임 상태, 저장 마이그레이션, reducer.
- `src/lib/world-store.ts`: 브라우저 저장소 어댑터.
- `src/components/hyunjun/`: 마을/러너/농장/집 UI와 공통 SVG 아트.
- 기존 TanStack Router 구조를 유지하고 `/`, `/race`, `/greenhouse`, `/house`를 사용한다.

## 검증 기준
- 순수 게임 로직은 node:test로 테스트한다.
- `npm test`, `npm run lint`, `npm run build`가 GitHub Actions에서 모두 통과해야 한다.
- 모바일 폭 360px 기준으로 화면이 가로 스크롤 없이 동작해야 한다.
- 러너 탭, 농장 반복 터치, 가구 배치가 텍스트 입력 없이 수행되어야 한다.
- PR은 검증된 feature branch SHA만 대상으로 생성한다.
