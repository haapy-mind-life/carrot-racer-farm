# 12. 할로윈 파티 + 집 꾸미기

요구: 할로윈 파티 추가, 집 꾸미기, 집 안에서 움직이며 내부 꾸미기.

## 구현
- 집 안(대왕집)에서 걸어 다니며 "집 안 꾸미기" 패널로 현재 위치에 장식 배치 (최대 24개, 별코인 소모, 치우면 절반 환급).
- 마당 꾸미기 4종(현관 호박·전구·깃발·대문 유령) — 우리 집 외관에 표시.
- 할로윈 장식 3개 이상이면 파티 시작 → 집 안 5곳의 사탕 줍기(개당 5코인, 첫 완료 보너스 50코인).
- 저장: `decor`, `yard`, `halloween` 필드 추가(구 저장은 마이그레이션 기본값, 버전 유지).

## 검증
- `npm test` 59 통과(장식·마당·파티 규칙, 저장 복원 포함).
- headless chromium으로 집 진입 → 장식 3개 배치 → 파티 시작 화면 확인, 콘솔 오류 없음.
- 미검증: 실기기 터치 UAT, 휴대폰 폭에서의 꾸미기 패널 배치.
