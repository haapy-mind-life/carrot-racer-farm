## 불명확한 구간 (사용자 발화를 그대로 보존)

- **HWQ-01:** "자동차보다 더" — 수량을 100종보다 늘린다는 뜻인지, 자동차보다 더 큰 특수 탈것을 원한다는 뜻인지 아직 판단할 수 없다. 사용자가 요구한 핵심은 '지금보다 더'다.
- **HWQ-02:** "아빠 로봇" — 아빠 모습으로 닮은 캐릭터, 로봇 동료, 집에 있는 NPC, 기능형 도우미 중 어떤 행동을 원하는지 미정. 사진/실제 외형을 임의 수집·사용하지 않는다.
- **HWQ-03:** (후속 피드백에서 사용자가 '비행기도 추가'를 요청 → 같은 요청일 가능성, 확정 아님. HW-013 참고) "비상도 만들어줘" — 비상 상황·비상벨·비행기·다른 사물 등을 의미하는지 불명확. **별도 신규 기능으로 단정하지 말 것.**
- **HWQ-04:** 큰 집의 층수·방·문·부엌·가구 조작, 음식 보관/선택 방식 미정.
- **HWQ-05:** 바다의 스케일, 육지 연결 방식, 잠수함 내부 조작/승객 여부 미정.
- **HWQ-06:** 푸드트럭 조리 과정이 필요한지, 손님의 자율 이동과 자동 주문을 원하는지, 가격과 별코인 사용처 미정.
- **HWQ-07:** 바다 잠수는 기존 호수 잠수와 같은 조작인지, 잠수함/몸 잠수가 모두 가능한지 미정.

## 공통 경험 수락 조건

1. 주인공을 직접 움직여 대상에 도달해야 하며, 액션 뒤 **월드 안에서 시각적 결과**가 보인다.
2. 새 지역과 기존 10개 마을 사이 길찾기·복귀에 막다른 구간이 없어야 한다.
3. 오픈월드 상태 전환 도중 전화 신고/사이렌/차량 탑승/지도 열기가 충돌하지 않는다.
4. 저장 후 새로고침하여도 기존 지갑·가구·자동차 선택·러너 기록이 사라지지 않는다.
5. 모든 기능은 소리 없이도 이해 가능하고, 실패는 부드러운 메시지로 복구 가능하다.
6. 완료 보고는 **코드 존재 / 테스트·CI 통과 / Pages 배포 / 실제 기기 확인**을 각각 표시한다.

## 범위 경계

- 별도 오션 미니게임, 버튼 한 번으로 매출만 주는 장사, 잠수함 그림만 바꾸는 탑승은 사용자 의도를 충족하지 못한다.
- 실제 응급 구조 교육, 실제 돈·결제, 사람 닮은꼴 생성, 네트워크 멀티플레이는 요구사항에 없으며 기본 제외.
- 모든 제안 가격·NPC 수·지도 크기 수치는 **승인 전 가설**이다.
