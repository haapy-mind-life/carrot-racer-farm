## 목표 — 아이가 직접 즐기는 큰 세계

현준이는 지금의 작은 집과 마을을 넘어, 넓은 집에서 음식과 물건을 다루고, 아빠 로봇 친구와 돌아다니며, 바닷가에서 잠수함을 타고 바닷속을 탐험하고, 푸드트럭으로 손님에게 음식을 팔아 별코인을 벌고 싶어 한다.

**가장 중요한 불변 원칙:** 메뉴를 눌러 별도 미니게임으로 전환하는 것이 아니라 **동일한 월드에서 실제 장소를 찾아 이동·탑승·상호작용한다.** 다만 푸드트럭 주문 목록처럼 맥락에 맞게 열리는 작은 메뉴는 요청에 포함된다. 기존 러너/농장/집 기능을 삭제하지 않는다.

## 제품 수준 구분

- **FACT**: GitHub 파일/커밋/Actions 실행으로 확인한 사실. 실제 UX 확인은 별도.
- **REQUEST**: 현준이와 보호자가 직접 말한 희망 사항.
- **PROPOSED**: 합의 전, 구현 방향을 이해하기 위한 가설/선택지.
- **UNKNOWN**: 전사만으로 정확히 판별할 수 없거나 구현 계약이 정해지지 않은 부분.
- **GATE**: 다음 단계 시작 전 통과해야 할 확인 항목.

## 최소 체험 가설 (확정 범위 아님)

바로 100개 기능을 한꺼번에 구현하지 않고, **한 번의 연속 플레이**에서
'주인공이 집에서 음식 들기 → 아빠 로봇과 이동 → 푸드트럭 주문 하나 판매 → 별코인 증가 → 해변으로 이동 → 잠수함에 탑승해 바닷속으로 내려가 다시 돌아오기'를 메뉴 화면 전환 없이 시연할 수 있다면 방향이 맞는지 확인할 수 있다.

이는 **검증용 제안**일 뿐 요구사항 삭제·범위 축소 승인으로 해석하지 않는다.
