## 테스트 계층

1. **Unit / node:test:** 월드 경계, 잠수함 상태 전환, 동일 판매 ID 중복 적용 금지, money 상한/음수, 메뉴 식별자.
2. **Integration:** 게임 상태와 localStorage 신규 필드의 저장·마이그레이션·오류/재시도.
3. **Browser:** 같은 URL에서 장소 이동/손에 물건 표시/주문·코인/HUD 변화.
4. **Performance:** 데스크톱/태블릿 양쪽에서 맵 영역 전환 중 프레임 저하·메모리 급증·초기 로딩을 측정.
5. **Real-device UAT:** Samsung Browser + 실제 손가락 및 S Pen. 아동이 직접 조작하도록 보호자가 관찰한다.

## 출시 중단(FAIL) 조건

- 새 기능 수행을 위해 별도의 '미니게임 선택' 페이지로 사실상 보내 버림.
- 게임 진입 불가 / 기본 조이스틱 미동작 / 10개 마을 또는 러너·농장·집 삭제.
- 주문 중복 보상, 과거 저장/돈 소실, 바닷속에서 탈출 불가.
- 요청 메뉴 누락 또는 같은 색만 바꾼 대왕/황금 피자로 구분 안 됨.
- 화면이 너무 작아 어린이가 대상/버튼을 누를 수 없음.
- 실제 개인정보·현금 결제/광고를 요구하지 않았는데 추가함.
