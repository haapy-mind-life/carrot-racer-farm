# 왼쪽 조이스틱과 오른쪽 조작 버튼

- 왼쪽 원형 조이스틱: 손가락/펜을 민 방향으로 이동, 손을 떼면 정지. 중앙 dead zone과 대각선 입력 지원.
- 오른쪽 놀이·대화 버튼 및 지도 버튼: 화면 하단 고정. 가까운 대상이 없을 때에도 눌러 화면 내 안내 표시.
- 미니게임의 이동에도 공용 조이스틱 적용. 오른쪽 쉬기 버튼 제공.
- 기존 방향키의 포인터 캡처 실패 시 입력 등록이 중단되는 경로 보완. 새 조이스틱은 전역 이동/해제 이벤트로 캡처 실패, 영역 밖 해제, 취소를 처리.
- Pointer Events 없는 환경은 Touch Events 사용. 두 번째 손가락은 이동을 가로채지 않음.
- 게임 저장 초기화는 이동 입력을 막지 않음. 보상·상호작용은 기존 ready 보호 유지.
- 조이스틱 안내와 대화 메시지를 화면 안에 표시. 지도 열기/미니게임/화면 전환 시 이동 입력 초기화.

검증: npm test 34개, npm run lint, npx tsc --noEmit, npm run build 통과. 별도 코드 검토에서 important/critical 지적 없음.

Chromium 터치 모의 입력으로 390×844, 844×390, 1280×800 화면에서 조작부가 화면 안에 있는지 및 이동/해제를 확인. 포인터 캡처를 강제로 실패시켜도 이동과 영역 밖 해제가 동작함. 오른쪽 안내/지도, 별 모으기 미니게임 이동과 쉬기 동작 확인.

실제 사용자 기기의 기존 입력 불능 원인은 아직 단정할 수 없음. 실제 서비스 배포 및 Samsung Browser/S Pen 실기기 검증은 별도 확인 필요.
