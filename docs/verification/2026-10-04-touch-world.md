# 터치 조작과 열 개 마을 업데이트

## 요청과 반영

- 손가락·펜용 화면 방향키를 기본 안내로 표시. 50–60px 버튼을 누르는 동안 이동하고 떼면 정지.
- 키보드와 여러 포인터 입력을 분리하고 화면 전환·포커스 상실 시 입력 초기화. 한글 배열에서도 물리 WASD/E 키 인식.
- 기존 보물찾기·별 모으기에 공용 터치 방향키, 낚시에는 터치 중심 안내. 러너·농장·집의 기존 터치 동작 유지.
- 월드 2800×1800 → 5600×1800, 면적 2배. 동서 경계를 넘으면 반대편으로 연결. 북남 경계는 유지. 실제 3D 구체가 아닌 2D 순환 월드와 둥근 여행 지도.
- 우리·캐릭터·부장·무한·농장·습동·에메랄드·파인애플·사과·다이아몬드 마을. 지도에서 각 마을로 이동 가능.
- 마을별 친구 10명. 가까이서 대화하며 농장 아저씨와 오버 친구 포함. 기존 보리 돌보기 유지.
- 별자리 공방: 손가락/펜 드래그 또는 순서대로 탭, 시간 제한 없이 별 6개 연결. 완료 보상 및 최고기록 저장, 중복 정산 방지.
- 기존 코인·가구·농장·러너·미니게임 기록 마이그레이션 유지.

## 검증

- `npm test`: 33개 통과.
- `npm run lint`: 통과.
- `npx tsc --noEmit`: 통과. 기존 농장 배열 접근과 테스트의 undefined 검사도 정리. 라우트 생성 파일에 /house 포함.
- `npm run build`: 클라이언트·서버 빌드 통과.
- Chromium / Playwright: 실제 CDP touchStart/touchEnd로 방향키 이동 및 정지, 지도 목적지 10개, 다이아몬드 마을 여행과 친구 대화 확인.
- CDP pen 이벤트로 별 6개 순서대로 탭, 완료 화면 및 localStorage 최고기록 확인.
- 보물찾기·별 모으기 터치 이동, 농장 심기, 집 경로, 러너 터치 시작 확인.
- 390×844 화면 가로 넘침 없음 및 방향키 표시 확인. JavaScript pageerror 없음.
- 독립 코드 검토: critical/important 지적 없음.

## 확인 범위와 한계

- 사용 기기의 최초 키보드 입력 불능은 직접 재현하지 못함. 한글 배열의 e.key 의존을 보완하고 화면 조작으로 플레이 가능하도록 변경.
- 자동 검증은 Chromium의 터치/펜 모의 입력. 실제 Samsung Browser·S Pen의 감도와 손바닥 입력은 실기기 확인 필요.
- 검증 환경에서 외부 Google Fonts 요청이 실패하여 스크린샷의 한글 글꼴은 검증하지 못함. 게임 조작과 저장 검증은 통과.
- 마을 친구는 대화형 NPC이며 자율 이동·동행 AI는 포함하지 않음.
