## 공용 기억/문서 정책

- 저장소 루트 [MEMORY.md](../MEMORY.md)를 새 에이전트의 시작점으로 사용한다.
- 문서는 반드시 **FACT(코드/CI 증거) / REQUEST(사용자 요구) / PROPOSED(설계안) / UNKNOWN(미결정)**를 구분한다.
- 요구사항 변경은 번호가 있는 등록부와 결정 장부에 반영한다.
- 아동 게임의 안전, 개인정보 보호, 실제 결제 배제, 조작 접근성을 우선한다.
