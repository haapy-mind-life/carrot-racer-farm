# 박현준 게임 — 아늑한 농장 + 달리기

닌텐도/팔리아 같은 포근하고 따뜻한 분위기의 2D 게임. 크게 세 곳을 오갑니다.

## 화면 구성

```text
        [ 집 화면 (메인) ]
        내 돈 / 티켓 진행도
      ┌──────┬──────────┐
   [레이싱]        [식물하우스]
      └── 집으로 돌아가기 버튼 ──┘
```

## 1. 레이싱 (달리기)
- 박현준 러너와 비슷한 방식: 캐릭터가 자동으로 달리고, 좌우로 움직여 장애물을 피하고 코인을 먹습니다.
- 부딪히면 끝나고, 모은 코인이 그대로 돈이 됩니다.
- 화면에 항상 "집으로 돌아가기" 버튼이 있어 언제든 집으로 갈 수 있습니다.

## 2. 식물하우스
- 상점에서 돈으로 씨앗을 삽니다.
- 심을 수 있는 것 (싼 것 → 비싼 것):
  - 무(10원) → 사탕무(100원) → 양상추(300원) → 당근(1000원) → 해바라기(1만원) → 황금 해바라기(상상 속 꿈의 작물)
- 황금 해바라기는 특별 수확 이벤트처럼 드물게 등장해 큰 돈을 줍니다.
- 밭 칸을 눌러 씨앗을 심고, 물뿌리개 버튼으로 물을 줍니다. 물을 줄 때마다 한 단계씩 자라고, 다 자라면 수확해서 팔아 돈을 법니다.
- 실제 시간을 기다릴 필요 없이 물 주기로 바로바로 자랍니다.

## 3. 집 + 티켓
- 집 화면에 지금 가진 돈과 티켓 목표가 크게 보입니다.
- 돈을 충분히 모으면 티켓을 살 수 있고, 사면 축하 화면이 뜹니다.
- 어떤 화면에서든 "집으로 돌아가기" 버튼으로 돌아옵니다.

## 저장
돈, 심어둔 작물, 티켓 보유 여부는 이 기기에 저장되어 다시 들어와도 그대로 남습니다.

## 만드는 방식 (기술 메모)
- TanStack Router 라우트 3개: `/` (집), `/race`, `/greenhouse`
- 게임 상태는 로컬 스토리지 기반 커스텀 훅 하나로 공유
- 레이싱은 canvas 또는 DOM 기반 간단 루프, 키보드 + 화면 터치 버튼 지원
- 팔리아풍 팔레트/폰트를 디자인 토큰으로 정의, 그림 에셋은 생성해서 사용
- 백엔드 없음
